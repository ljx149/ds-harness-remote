# Xcodex Remote 0.7.0-xcodex.2

## 修复空会话和自动标题

- 空白状态按用户是否发送过消息判断；模型初始化、模型选择、重命名及初始化诊断不会把草稿变为正式对话。切换其他会话后，DSH 原生列表隐藏未聊天草稿，不删除数据。
- 首条用户消息生成简短标题（文本回退标题，不额外调用模型）；持久化原生 session/title 事件。保留手动标题，重启后仍有效。
- 对旧版有消息但仍为默认名字的会话，从已有首条消息派生展示标题；不覆盖已有自定义名字。
- 手动重命名返回原生所需 seq，并同步持久事件。
