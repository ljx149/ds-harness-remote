## 实际移除

- 删除管理面板源码及其原生会话标题区注册，清除旧构建产物，包校验禁止该入口重新进入 bundle。
- 删除后端的高级操作编排：上下文/额度/命令/设置查询、手动压缩、回退、分叉、目标、MCP 和后台任务控制、独立启动配置面板操作。
- 移除 management 读取接口的本地控制与远程允许列表；直接调用也明确拒绝。
- manage 写接口只接受消息队列和 Agent 问题回答三种聊天控制，旧高级请求在调用 Provider 前拒绝。
- 对客户端声明 fork/rewind/compact/threadGoal/contextUsage 为 false，避免客户端继续展示入口。

## 为什么不是全部删除 Orca 或退回旧版本

SDK/Provider 内部辅助代码存在交叉依赖：正常模型设置、结构化问题、后台任务存在性判断、进程安全退出仍会复用。此轮保留这些内部代码及其测试，但不再提供高级远程操作入口。这是按用户功能边界收回产品能力，不是声称底层所有高级 SDK 代码都已删除。

持久化层仍保留旧回退/分叉相关记录和格式兼容。不会删除既有分叉会话、改变 Provider ID、清空历史、重置身份或让未知操作自动重放。保留未知结果保护是为了避免重复执行，不是恢复管理面板。

原生模型/推理强度选择、发送/停止、权限审批、自动标题/重命名/归档仍使用原来的聊天接口。结构化问题回答协议保留；本轮未新增专用问题 UI，也不将其端到端交互列为验收通过。

## 回归门槛

- 原生侧栏、命名归档、队列、进程保护、持久化和重启认证恢复继续通过测试。
